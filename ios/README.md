# RepairOS iOS

iPhone 16 Pro / Pro Max, SwiftUI + ARKit (BUILD.md §2.1). The Xcode project lands with card C1.1.

- Xcode 26.x, Swift 6 (strict concurrency), deployment target iOS 18.0. Record the exact Xcode build here at C1.1.
- `RepairOS/Contracts/Contracts.swift` is generated by `make codegen` from `spec/contracts/` (quicktype). Never edit
  it; `make codegen-check` fails on drift. All examples in `spec/contracts/examples/` decode with it (backend test
  `test_examples_decode_in_swift`, run with `swiftc -swift-version 6`).
- Signing: `ios/Config/Signing.xcconfig` (gitignored) with `DEVELOPMENT_TEAM`.
- The phone holds no keys; it talks only to the backend gateway (A6).
